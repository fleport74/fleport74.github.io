# fleport74.github.io

Personal site: AI / Product Engineer.

Static, dependency-free: vanilla HTML/CSS/JS plus one `<canvas>`.
The hero is a particle field that morphs between four shapes
(solitaire ring, waveform, neural net, honeycomb) sampled from
line segments. Press `/` on the site for the interactive console.

## Local preview

```sh
python -m http.server 5173
# open http://localhost:5173
```

Deployed automatically by GitHub Pages from `main`.
